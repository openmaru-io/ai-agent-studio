# CogentAI SQL 진단

이 스킬은 MCP 서버 `cogentai-database` 의 도구 `mcp__cogentai_database__diagnose_sql` 을 언제, 어떻게 쓰는지 정한다. 이 도구는 느린 SQL 의 실행 계획을 진단하고 튜닝 방법을 제시한다.

CogentAI 가 실행 계획을 읽고 진단한다. 이 스킬은 SQL 을 직접 실행하거나 고치지 않는다.

## 1. 먼저 연결을 확인한다

- `mcp__cogentai_database__` 도구가 없으면 CogentAI 가 연결되지 않은 것이다. 이렇게 안내한다:
  「AAS 의 내 AI 에이전트 > 프로파일 > 도구 탭 > 새 MCP 서버 > 카탈로그에서 cogentai-database(CogentAI SQL 진단)를 고르고, 관리자에게 받은 MCP 주소(…/mcp)와 키를 넣으세요. 넣은 뒤 「새 대화」로 다시 물어 주세요.」
- 키를 대화에 붙여 넣으라고 하지 않는다. 사용자가 키를 대화에 붙여 넣으면 쓰지 말고, 관리자에게 키를 바꿔 달라고 하라고 안내한다.
- `manage_connections`·`setup_mcp` 를 부르지 않는다. CogentAI 는 이미 연결된 MCP 서버다.

## 2. 도구를 부르는 방법

- `mcp__cogentai_database__` 도구는 처음에 목록에 없다(지연 등록). `tool_describe` 로 불러온 뒤 **`tool_call` 로 부른다.** 이름으로 직접 부르면 「does not exist」로 실패한다(OKE 2026-11-08 확인).
- `tool_call` 의 `calls` 는 JSON 배열로 넘긴다(`[{"name": …, "arguments": {…}}]`). 문자열로 만들어 넣지 않는다. SQL 의 따옴표·`%` 를 JSON 문자열 안에 넣다가 이스케이프가 깨져 「`calls` is not valid JSON」 으로 실패한 적이 있다. `execute_code`·`terminal` 로 감싸서 부르지 않는다.
- 한 질문에 도구는 한 번 부른다. 결과가 왔으면 같은 인자로 다시 부르지 않는다. 다시 부르는 경우는 4절의 시간 초과뿐이다.

## 3. SQL 진단

- 사용자가 느린 SQL 을 주고 원인이나 튜닝을 물으면 `diagnose_sql` 을 부른다.
  - `sql` 에는 사용자가 준 SQL 원문을 그대로 넣는다. 바인드 변수·주석을 지우지 않는다.
  - `connection_id` 는 사용자가 DB 를 말했을 때만 넣는다. 사용자가 DB 를 별칭(예: 「청약 검증 DB」, 「운영 DB」)으로 말하면 그 말을 `connection_id` 에 그대로 넣는다. 도구가 별칭을 연결로 바꾼다(대소문자·공백 무시). 모르면 넣지 않고 부른다. 이 키로 쓸 수 있는 연결이 하나면 도구가 그 연결로 실행 계획·통계를 직접 읽는다. 사용자에게 실행 계획이나 통계를 먼저 달라고 하지 않는다.
  - 「어느 DB 에서 느린 SQL 인지 connection_id 로 지정해 주세요. 쓸 수 있는 연결: …」이 오면, 그 연결 이름(괄호 안은 별칭)을 선택지로 `clarify` 에 「어느 DB 에서 느린가요?」를 묻고 고른 연결로 다시 부른다. 연결 목록을 지어내지 않는다.
  - 답 언어는 `lang` 에 `ko` 또는 `en` 으로 넣는다.
- 결과의 진단 Markdown(실행 계획·인덱스·통계·권고)을 첫 줄부터 그대로 보인다. 다시 쓰거나 요약하지 않는다.
- **권고를 실행하지 않는다.** 인덱스 생성·통계 수집·힌트 적용·DDL 은 사람이 검토하고 실행한다. 사용자가 실행을 부탁하면 그렇게 안내한다.
- 사용자가 준 SQL 이 쓰기 문장(INSERT·UPDATE·DELETE·DDL)이면 진단만 하고, 실행 결과를 말하지 않는다.
- 이 도구는 업무 통계 질문(「지난달 매출은?」 같은 질문을 SQL 로 바꿔 답하기)을 하지 않는다. 그런 질문에는 이 설치에서 쓸 수 있는 통계 질문 도구가 없다고 안내한다. SQL 을 지어내 답하지 않는다.

## 4. 시간과 오류

- 도구는 2~3분 안에 끝난다. 「시간 초과」가 오면 한 번만 다시 부른다. 두 번째도 시간 초과면 잠시 뒤 다시 물어 달라고 안내한다.
- 401·403 이 오면 키가 틀렸거나 바뀐 것이다. 카탈로그에서 키를 다시 넣으라고 안내한다.
- 「허용하지 않은 연결」이 오면 그 DB 는 이 키로 쓸 수 없다. 관리자에게 연결 허용을 요청하라고 안내한다.
