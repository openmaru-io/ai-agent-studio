# law.go.kr 법령 조회

이 스킬은 MCP 서버 `law-go-kr`(법령 조회 커넥터 `law-connector`)의 도구를 언제, 어떻게 쓰는지 정한다.
서버 이름의 하이픈은 도구 이름에서 `_` 로 바뀐다.

- `mcp__law_go_kr__search_law`: 법령·행정규칙 이름으로 찾는다. 이름·법령 ID·MST·시행일·구분을 돌려준다.
- `mcp__law_go_kr__get_article`: 법령 하나의 조문 하나를 가져온다. 조문 제목·본문·시행일·링크를 돌려준다.
- `mcp__law_go_kr__verify_citation`: 글 안의 조문 인용마다 현행 법령과 맞는지 대조한다.

## 1. 먼저 연결을 확인한다

- `mcp__law_go_kr__` 도구가 없으면 법령 조회 커넥터가 연결되지 않은 것이다. 이렇게 안내한다:
  「AAS 의 내 AI 에이전트 > 프로파일 > 도구 탭 > 새 MCP 서버 > 카탈로그에서 law-go-kr(law.go.kr 법령 조회)를 고르고, 관리자에게 받은 MCP 주소(…/mcp)와 키를 넣으세요. 넣은 뒤 「새 대화」로 다시 물어 주세요.」
- 키를 대화에 붙여 넣으라고 하지 않는다. 사용자가 키를 붙여 넣으면 쓰지 말고, 관리자에게 키를 바꿔 달라고 하라고 안내한다.

## 2. 도구를 부르는 방법

- 도구는 처음에 목록에 없을 수 있다(지연 등록). 없으면 `tool_describe` 로 불러온 뒤 **`tool_call` 로 부른다.** `calls` 는 JSON 배열로 넘기고 문자열로 만들지 않는다. `execute_code`·`terminal` 로 감싸지 않는다.
- 같은 조문을 한 대화에서 여러 번 부르지 않는다. 앞 결과를 다시 쓴다.

## 3. 언제 부르는가

- 사용자가 법령·조문 내용을 묻거나, 답에 조문을 근거로 달아야 할 때 부른다. 조문 내용을 기억으로 쓰지 않는다.
- 답이나 초안에 「○○법 제N조」 같은 인용이 있으면 내보내기 전에 `verify_citation` 으로 대조한다.
- 웹 검색으로 조문을 찾지 않는다. 웹 검색은 사용자가 직접 부탁할 때만 쓴다.

## 4. 넣는 값

- `search_law` 의 `query` 에는 **법령 이름만** 넣는다(100자 이하). 민원 문장·질문 글을 넣지 않는다. 그 글이 법제처로 나간다.
- 행정규칙(지침·고시)은 `search_law` 에 `kind: "admrul"` 을 준다.
- `get_article` 은 `law`(정확한 법령 이름)·`law_id`·`mst` 가운데 하나와 `article`(「제53조」「53」「제53조의2」)을 준다. 시행령·시행규칙은 이름 전체를 쓴다(예: 「주택법 시행령」).
- `verify_citation` 의 `text` 는 20,000자, 인용 50개까지다. 넘으면 나눠 부른다.

## 5. 결과를 쓰는 법

- 조문을 근거로 달 때는 결과의 `link`·`effective_date`(시행일)를 함께 적는다. 예: 「[주택공급에 관한 규칙 제53조(주택소유 여부 판정기준)](link) — 시행 YYYY-MM-DD」.
- `truncated: true` 면 본문 일부만 받은 것이다. 인용할 때 「본문 일부」라고 적고, 필요하면 링크로 전문을 보라고 안내한다.
- `ambiguous` 면 고르지 않는다. 후보(`candidates`)를 보이고 어느 법령인지 묻거나, 이름 전체로 다시 부른다.
- `not_found`(조문 없음)·`law_not_found`(법령 이름 없음)·`not_current`(현행이 아님)·`title_mismatch`(조문 제목이 다름)는 그 인용이 틀렸다는 뜻이다. 그 인용을 그대로 쓰지 않고, 무엇이 다른지 적는다.
- `unparsed` 는 커넥터가 그 인용을 해석하지 못했다는 뜻이다(약칭·이름 없는 조문 번호). 맞다고도 틀리다고도 쓰지 않는다. 「확인하지 못한 인용」으로 따로 적는다.

## 6. 법제처 장애

- 도구 결과가 `isError: true` 면 법제처 조회가 실패한 것이다(`rate_limited`·`upstream_5xx`·`timeout`·`network`·`oc_rejected`). **조문이 없다고 쓰지 않는다.** 「법령 확인을 하지 못했습니다(법제처 응답 없음). 잠시 뒤 다시 확인해 주세요」라고 적고, 확인하지 못한 조문을 목록으로 남긴다.
- `oc_rejected` 는 설치 설정 문제다. 「관리자에게 법령 조회 커넥터의 인증값·IP 등록 확인을 요청해 주세요」라고 안내한다.
- 같은 호출을 바로 되풀이하지 않는다. 커넥터가 이미 다시 시도했다.
